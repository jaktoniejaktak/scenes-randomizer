# B99: B94 bundle with Scene lock scopes

This uses the same module bundle as B94: USB MIDI, sidechain, RPS9, MIDI
velocity, Play Modes 2/4 and Transient. The temporary track-length shortcut
from B98 is not part of this remix.

Hold Scene A or B and press a parameter page key to randomize that page's
existing locks on the selected track. Press T1–T8 to randomize every page on
that track. Press YES to randomize existing locks on every audio track and
page in the current Part. Scene + NO has no custom action. Page and track
selection continue through the stock key handler.

The scene locks update in Part memory, its battery-backed copy and the live
A/B pair. The new shortcuts have not yet been checked on the Octatrack.
